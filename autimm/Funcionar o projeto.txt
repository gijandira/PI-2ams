1. Baixe e descompacte a pasta do projeto em Documents do PC.
2. Abra a pasta no VS Code.
3. Ligue o Apache e o MySQL no XAMPP.
4. Crie o banco de dados:
   CREATE DATABASE autim;

5. Importe o arquivo SQL do projeto para o banco:
   - autimm/autim.sql
   - ou o arquivo equivalente dentro da pasta do projeto

6. Abra o terminal na pasta raiz do projeto:
   cd C:\Users\SeuUsuario\Documents\PI-2ams-mainOK\autimm

7. Instale as dependências do frontend:
   npm install

8. Instale as dependências do backend:
   cd backend
   npm install

9. Dependências atuais do backend instaladas:
   npm install cors
   npm install mysql2
   npm install dotenv
   npm install bcryptjs
   npm install jsonwebtoken
   npm install multer
   npm install nodemailer
   npm install node-cron
   npm install express
   npm install ollama

10. Dependências do frontend/React/Vite já utilizadas no projeto:
    npm install react
    npm install react-dom
    npm install vite
    npm install @vitejs/plugin-react

11. Para rodar a aplicação frontend:
    cd ..
    npm run dev

12. Para rodar o backend local:
    cd backend
    node server.js

13. Ou em modo de desenvolvimento:
    npm run dev

14. O backend fica na porta:
    http://localhost:3001

15. O frontend fica normalmente em:
    http://localhost:5173

16. Antes de testar a IA, o Ollama precisa estar rodando localmente:
    ollama serve

17. Se o modelo não estiver baixado:
    ollama pull qwen2.5:0.5b

18. A IA do projeto usa o modelo:
    qwen2.5:0.5b

19. Rota da IA do backend:
    POST http://localhost:3001/ia/perguntar

20. Exemplo de requisição:
    {
      "mensagem": "Onde fica a página de Comunicação?"
    }

21. O backend da IA responde em JSON e o frontend lê essa resposta para mostrar a conversa no chat.

22. Observação importante:
    Se o backend não estiver rodando na pasta correta, o frontend receberá HTML/erro em vez de JSON e aparecerá o erro:
    "Token inesperado '<', "<!DOCTYPE ..." não é JSON válido"

23. Para adicionar um novo botão de áudio na tela de comunicação:
    INSERT INTO midia (MID_TIPO, MID_URL, MID_ROTULO, MID_EMOJI, MID_BG_COLOR, MID_SHADOW_COLOR, CAT_ID)
    VALUES ('audio', 'speech:Ansioso', 'Ansioso', '🤍', '#9c27b0', 'rgba(156,39,176,.45)', 1);

24. A tela de Comunicação puxa os itens do banco automaticamente.

25. Resumo rápido para rodar o projeto:
    - XAMPP: Apache + MySQL ligados
    - Banco criado e importado
    - cd autimm
    - npm install
    - cd backend
    - npm install
    - (na pasta do Ollama) ollama serve
    - ollama pull qwen2.5:0.5b
    - cd ..
    - npm run dev
    - cd backend
    - node server.js

26. Se o projeto estiver funcionando com esse fluxo, pode seguir normalmente com as instruções acima sem alterar o setup básico.
