# Frontend

O frontend React/Vite faz parte do repositorio Autim. Consulte
[`../README.md`](../README.md) para a visao geral e
[`../docs/EXECUCAO-LOCAL.md`](../docs/EXECUCAO-LOCAL.md) para instalar as
dependencias e iniciar frontend e backend.

Comandos executados a partir da raiz:

- `npm run dev:frontend`
- `npm run build:frontend`
- `npm run lint:frontend`
